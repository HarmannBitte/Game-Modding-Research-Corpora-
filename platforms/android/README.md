# Android platform scope

This is a platform-scope note for the game-modding index, not a general Android app-modification guide.

## What is covered

- The platform checklist marks Android **Covered only for official, game-integrated user-generated content (UGC)**. A game must implement the UGC service and meet any required platform approval; the platform listing alone does not provide a mod API.
- [mod.io's UGC documentation](https://docs.mod.io/getting-started) describes developer integrations. It is an integration path for a participating game, not a generic Android game or app modding tool.
- The mobile checklist as a whole remains **Partial**. Its narrow approved-UGC coverage does not establish a general workflow across Android, iOS, native apps, Unity, or Unreal.

## Explicitly not covered

- General modification of arbitrary Android apps or games.
- Rooting, APK repackaging/patching, or access-control circumvention instructions.
- Compatibility claims for a particular Android game, device, app-store build, or mod unless a separately reviewed upstream source supports that claim.

The [official DDLC mobile announcement](https://teamsalvato.com/news/ddlc-is-now-available-on-ios-and-android/) describes a separate mobile release; it does not establish compatibility with desktop Ren'Py tools or an Android mod API. Serenity Forge's [statement about Google Play removal](https://x.com/SerenityForge/status/2042355439824769399) is a distribution-status reference, not mod-support evidence.

See the main [ecosystem coverage audit](../../ECOSYSTEM_COVERAGE.md#platform-and-distribution-checklist) for the full Android, iOS, mobile, and approved-UGC boundaries. This page adds no new modding route or compatibility claim.
